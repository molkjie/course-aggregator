# ADR-002. Вибір стратегії посторінкової пагінації для каталогу курсів

Статус: прийнято, 2026-11-04

Контекст. Каталог курсів містить понад 200 записів із різноманітними фільтрами (за рівнем, платформою, темою). Необхідно повертати дані сторінками.

Розглянуті варіанти:
1) Пагінація зі зміщенням (OFFSET / LIMIT) — стандартна схема, дозволяє прямий перехід на довільну сторінку та відображення загальної кількості (total).
2) Курсорна пагінація (Keyset Pagination за created_at / id) — забезпечує стабільну швидкість на мільйонах записів, але ускладнює довільну навігацію за номерами сторінок.

Рішення. Обрано пагінацію зі зміщенням (OFFSET / LIMIT) із поверненням полів page, page_size, total.

Наслідки. Інтерфейс отримує зручну нумерацію сторінок для користувача; створено складені індекси в БД для прискорення запитів вибірки.

Умова перегляду. Збільшення розміру каталогу понад 500 000 записів або часте оновлення стрічки в реальному часі.
